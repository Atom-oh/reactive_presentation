"미국국채", "미국채", "US Treasury"는 같은 것. DB에는 BD_OVS_GOV 하나뿐입니다.

상식의 간극
"보수"는 fee_bp이고 단위는 bp(0.01%p). 담당자는 알지만 DB는 말해 주지 않습니다.

개념을 누르면 하위 개념과 해당 상품까지 함께 포함

개념 노드를 눌러 보세요예: "채권 ETF 보여줘". DB에 "채권"이라는 값은 없지만 계층을 따라가면 상품까지 이어집니다.
점선 테두리: 개념(클래스), 실선: 상품(인스턴스). 데모용 가상 ETF 22개 중 이 계층에 연결된 20개만 표시

사람의 말을 DB 값으로 확정하는 사전

대표 이름(prefLabel), 별칭(altLabel), 실제 값을 한 개념에 묶는 어휘(SKOS)

# etf_ontology.ttl (데모에 실제로 쓴 파일 일부)
ex:BdUSGov  a skos:Concept ;
    skos:broader   ex:BdOvsGov ;        # 상위: 해외국채
    skos:prefLabel "미국국채" ;
    skos:altLabel  "미국채", "미 국채", "US Treasury" ;
    ex:sqlFilter   "ast_cls = 'BD_OVS_GOV' AND rgn_cd = 'US'" .

# 업무 상식 (Semantic Layer)
ex:RuleFee  ex:trigger "보수" ;
    rdfs:comment "fee_bp 단위는 bp(1bp = 0.01%p)다. 0.1% = 10bp." .
질문 속 말: "미 국채 ETF 중 보수가 낮은 것"
사전 조회 (LLM 호출 없음)
개념 확정: 미국국채 (상위: 해외국채, 채권)
개념에 붙은 값
조건 확정: ast_cls = 'BD_OVS_GOV' AND rgn_cd = 'US', 규칙: 보수는 fee_bp(bp)
사전에 없는 말이면 추측하지 않고 되묻습니다. 미래에셋증권은 vocabulary.ttl로 같은 일을 합니다.
