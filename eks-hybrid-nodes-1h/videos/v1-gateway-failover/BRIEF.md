## Intent

60분 L200 세션 `eks-hybrid-nodes-1h`에서 라이브 데모 1(Gateway 리더 장애 조치)을 대신하는 무음 영상입니다. 발표자가 영상 위에서 설명하므로 소리와 내레이션이 없고, 화면 텍스트(한국어, 기술 용어는 영어)만으로 흐름이 읽혀야 합니다. 청중은 아키텍트와 의사결정자이므로 명령 세부보다 "무엇이 바뀌고 얼마나 걸렸는가"가 보여야 합니다.

## Customizations

- 장면 8개 (178초): (1) 환경 구성도, (2) 녹화: 시작 상태(Pod, Lease, VPC 라우트), (3) 평상시 경로, (4) 녹화: failover.sh 실행, (5) 리더 Pod 삭제, (6) Lease와 라우트 교체, (7) 녹화: 전환 이후 상태, (8) 결과 4회 측정(이전 측정 3회 카드와 녹화 회차 카드).
- 녹화 장면(2, 4, 7)은 `../rec/r1-failover.mp4` 실제 터미널 녹화를 0.5배속(2, 4), 0.6배속(7)으로 재생하고, 화면에 배속 배지와 "실제 터미널 녹화, 대기 구간 줄임" 배지를 둡니다. 하단 표기는 "실측 터미널 녹화 (2026-10-18, 시뮬레이션 환경)".
- 재구성 장면(1, 3, 5, 6, 8)의 하단 표기: "실측 결과 재구성 (2026-10 시뮬레이션 환경)".
- 덱 테마 색: 배경 #161D26, 텍스트 #FFFFFF / #F3F3F7(흐리게), accent #41B3FF, warning #FBD332, success #00E500, danger #FF5C85.
- 프로젝터 가독성: 직접 만든 텍스트는 36px 이상(1080p). 녹화 화면 글자는 원본 비율 유지(약 24px).
