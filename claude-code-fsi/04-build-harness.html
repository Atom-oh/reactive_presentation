확정 전에 확인할 여덟 가지

  • 1 CRIS 국외 처리 고지와 DLP 범위
    국외이전 논리, SCP 예외 조건 → 신청서, 정보보호위원회에 명시
  • 2 연구개발망 조항 번호 표기 불일치
    규정 원문 대조
  • 3 OpenAI 모델 서울 in-region 없음
    Codex는 CRIS 전제, Global / US 국외 처리 고지
  • 4 AgentCore Policy 정책 엔진 처리 리전
    문서 확인 (Gateway, Policy 자체는 서울 가용)
  • 5 AWS Context 서울 지원
    확인 필요. Managed Knowledge Base, KB GraphRAG는 서울 미지원이라 대체안으로 설계
  • 6 LLM Gateway 배치 위치 (전산실 vs AWS)
    금보원 컨설팅
  • 7 망분리 전면 해제 일정
    모니터링
  • 8 KB증권 지정 부가조건 원문 미확인
    보도 기반임을 명시
면책: 규제 해석은 공개 자료 기반의 기술적 해석이며 법률 자문을 대체하지 않습니다. 하나증권 컴플라이언스, 법률 검토를 거쳐 확정합니다.
