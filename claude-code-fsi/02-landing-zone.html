막고, 찾고, 만들기 전에 검사한다

Preventive (예방)
허용되지 않은 작업 자체를 거부
구현: SCP
예: 서울 리전 외 사용 금지, Log Archive 정책 변경 금지
Detective (탐지)

예: 루트 계정 MFA 미설정, S3 퍼블릭 읽기 허용 탐지
Proactive (사전 검사)

구현: CloudFormation 훅
예: KMS 암호화 없는 S3 버킷 생성 시도 차단
리스크: SCP는 잘못 적용하면 운영 계정을 한 번에 마비시킬 수 있습니다. Policy Staging OU에 먼저 적용하고 긴급 해제 절차를 문서화하십시오. SCP는 IAM 정책과 AND 조건으로 동작합니다.
SCP: OU, 계정이 쓸 수 있는 최대 권한 범위를 정하는 조직 정책. RCP: 리소스 쪽에 같은 방식으로 적용하는 정책
